# Start the app locally

Open this file in VS Code and press `Ctrl+Shift+V` (or `Cmd+Shift+V` on macOS) to open the Markdown preview, then click the link below to run the `Start Docker` task which launches the app locally via Docker Compose.

<a href="command:workbench.action.tasks.runTask?%5B%22Start%20Docker%22%5D">Start app locally (Docker)</a>

If you don't have Docker installed, run the helper scripts directly:

- Windows PowerShell: `.\scripts\start-docker.ps1`
- macOS / Linux: `./scripts/start-docker.sh`
